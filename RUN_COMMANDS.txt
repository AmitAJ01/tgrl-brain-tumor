3. PRIORITY 3: UNIT & INTEGRATION TEST SUITES
================================================================================
Run these tests to verify model architecture integrity, patient isolation,
loss functions, and metric calculation accuracy.

[3.1] Run All Unit Tests:
      Command:
        pytest tests/ -v

[3.2] Fast Architectural Smoke Test:
      Verifies tensor shapes, forward passes, and gradient flow for ResNet18,
      U-Net decoder, and TGRL multi-task network.
      Command:
        pytest tests/test_smoke.py -v

[3.3] Dataset Split & Zero Data Leakage Verification:
      Verifies that no patient ID overlaps across train, validation, and test.
      Command:
        pytest tests/test_dataset.py -v

[3.4] Multi-Task Loss Objectives Verification:
      Tests soft Dice + BCE segmentation loss, KL divergence TGC consistency
      loss, and counterfactual margin ReLU loss.
      Command:
        pytest tests/test_losses.py -v

[3.5] Metrics & Statistical Calibration Verification:
      Verifies confusion matrix math, macro/per-class F1, Expected Calibration
      Error (ECE), Brier score, and Dice/IoU calculation correctness.
      Command:
        pytest tests/test_metrics.py -v

4. PRIORITY 4: DATASET AUDIT & CACHE PREPARATION
================================================================================
These scripts verify the raw Figshare CE-MRI dataset and prepare preprocessed
tensors for high-speed training and evaluation.

[4.1] Comprehensive Dataset Inspection & Audit:
      Scans all 3,064 .mat slices, checks patient IDs, slice dimensions,
      missing values, and class distribution across Meningioma, Glioma, Pituitary.
      Command:
        python scripts/inspect_dataset.py
      Output:
        results/dataset_report.json
        results/dataset_report.md

[4.2] Preprocess & Build Memory Cache:
      Normalizes MRI slices (224x224), standardizes masks, and stores fast-loading
      compressed tensors partitioned strictly by patient ID.
      Command:
        python scripts/prepare_cache.py
      Output:
        data/cache/train.npz
        data/cache/val.npz
        data/cache/test.npz
        data/cache/splits_metadata.json
